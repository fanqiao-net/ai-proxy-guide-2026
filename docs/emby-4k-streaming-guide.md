## 一、挑「买机场送 Emby」最容易踩的 4 个坑

1. **低价档画饼，实际要买 ¥30–¥50+ 高档位才送 Emby**
   - 选购前看清「入门月付档」是否包含 Emby 权益。例如 [fanqiao·帆桥](https://fanqiao.net/cinema) 从 **¥10/月（入门 50G）**、**¥20/月（标准 300G）** 到高级/旗舰正式周期套餐**全系附赠帆桥影院私有 Emby 权益**，无需为看剧额外加买高价档。
2. **4K 码率 + 2x/3x 高倍率节点 = 一部电影烧掉 40 GB 套餐流量**
   - 一部 4K HDR 电影约 15–25 GB；如果机场把专线设为 2x 倍率，看两部电影就能耗掉近 100 GB。优先选择 **全站 100% 统一 1x 标准倍率**、且支持通过每日签到（如 `@fanqiao_bot` `/checkin` 每日送 100 MB–1 GB）回血的机场。
3. **浏览器网页播放强制服务端转码导致卡顿或被封号**
   - 成熟私有 Emby 服通常禁用网页端软解转码，以保护服务器并发流畅度。
   - **正确播放姿势**：
     - **iOS / macOS / Apple TV**：优先使用 **VidHub**、**Infuse 7.7+**（务必在「高级」中保持关闭「媒体库模式」即直连模式）或 **SenPlayer**，开启硬件直解即可秒开 4K HDR / 杜比视界；
     - **Windows / Android / 电视 / 鸿蒙**：使用 **小幻影视（Windows）**、**网易爆米花（全平台免费）**、**VidHub**、**AfuseKt / AfuseKtV**、**Hills**、**Yamby** 或 **hosplayer（纯血鸿蒙）**（原画直放服请勿用 Emby 官方客户端，手动填 HTTPS 时端口改填 `443`）。
4. **只顾送公费 Emby，主业代理节点连不上 AI 或晚高峰断流**
   - 买机场的核心依然是日常上网、ChatGPT / Claude 与 Netflix 稳定性。建议先花 ¥1 或低价月付实测晚高峰节点与播放器流畅度，再决定是否长期续费。

## 三、VidHub / Infuse / 网易爆米花快速添加步骤

1. 在套餐生效后进入影院门户（免绑 Telegram），一键授权并设置**专属播放用户名**（非机场登录邮箱）与**独立播放密码**；
2. VidHub / SenPlayer / 小幻影视可直接在门户点「一键导入」；Infuse 打开「设置 → 新增文件来源 → 添加 Emby → 其他 Emby」，在「高级」中选 `HTTPS`（端口 `443`）并**保持关闭「媒体库模式」**；
3. 手动添加（如网易爆米花、AfuseKt、Yamby）时主机只填纯域名，端口务必将默认 `8096` 改为 `443`，填入专属用户名与独立播放密码即可加载片库（帆桥官方订阅规则已将影院默认设为 `DIRECT` 直连，看 4K 不扣套餐代理流量）。
